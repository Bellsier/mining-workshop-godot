## 1. 제작품 50종 최종 권장 수치

- 투입·산출은 완제품 1개 기준이다. 1~18번 기존 행의 원광 이름은 원가 환산용 표기다. 실제 자원·레시피 ID 변경 여부는 4절을 따른다.
- **원광**은 전 재료를 v0.8 원광 가격으로 환산한 값이다. **즉시 투입**은 바로 앞 단계 중간품을 권장가로 팔 경우의 기회비용이다.
- 후보와 권장 열은 **판매가 G / 자체 제작 초**다. 기존 후보 자체 시간은 현행 카탈로그, 신규 후보 자체 시간은 v0.4의 3/7/15/30초다. **전체 초**는 하위 재료를 만드는 공정과 수량을 합산한다.

## 2. 수급·채굴·자동화 시뮬레이션

각 품목을 한 번에 하나씩 따로 생산한다. 행을 합하면 광맥·시설이 중복 집계된다. 2시간·8시간은 해당 품목의 원재료와 연구가 이미 열린 조건이다. 초기 탐색·지역 개척, 장비 및 연구 소비, 고갈 보상, 실물 운반, 납품, 오프라인 시간, 명성·본사 배율은 모델 밖이다. 판매 배율은 1, 판매 수수료 및 소비성 운영비는 0이다. 원광 수급률과 속도 배율은 실측 전 가정이다.

| 모델 | 광맥 확보 | 채굴 | 제작 |
|---|---|---|---|
| 30분 초반 | 석탄·구리·주석·철만 가용. 확보 빈도 기준의 0.5배 | 요구치 −4.7 경계의 속도 25%, 가동률 65% | 1개 카드, 가동률 75%. 한 사람이 채굴과 제작을 순차 진행 |

| 8시간 후반 | 자원 공급이 풍부해 확보 빈도 기준의 3배 | 속도 125%, 가동률 90% | 등가 라인 2개, 카드 시설·제작소 Lv.2, 가동률 95% |

1. 확정 진입 조건은 `채굴력 ≥ max(0, 요구 채굴력−4.7)`이다. 모델은 가격 15/75/350/850G 이하의 각 구간과 850G 초과 구간에 중형 매장량 가정 45/28/18/10/5개, 기준가 10/50/140/360/1,200G를 적용했다. 가격 구간은 실제 등급을 대신한 비교 기준이다. `매장량 = max(1, round(기본 수량 × clamp(sqrt(기준가/가격), 0.8, 1.2) × 크기 배율))`을 0.5/1/2/4배에 적용하고, 확정 크기 비중 50/30/15/3.5%로 가중 평균한 뒤 0.985로 나눴다. 특수 1.5%는 확정 수량이 없어 조건부 평균에서 제외했다.
2. 각 구간 분당 확보율은 0.55/0.35/0.22/0.12/0.06광맥으로 가정했다. 공급 한도는 평균 매장량×확보율×시나리오 빈도 배율이다. 수동 채굴 기본 시간은 각 구간 1/1.25/1.7/2.5/4초/개다. 자동은 확보 광맥 하나와 가상 일꾼 하나를 광물마다 배정한다. 비교 기준으로 광맥 채굴력 1, 등급 1~5, 등급당 0.4개/초, 일꾼 생산 `채굴2×운반2×이동1÷16`을 적용했다. 처리 한도는 이 기본 속도에 시나리오 채굴 속도와 가동률을 곱한 값이다. 분당 수급 `q`는 공급 및 처리 한도 중 작다.
3. 자동 모델의 원광 로트 간격은 `L=max(60×원광 필요량/q)`초다. 빈 재고에서 k번째 로트를 `k×L`에 배정하고 라인에서 하위 제작 공정부터 직렬로 끝냈다. 제작소 Lv.2는 해당 단계 속도 ×1.25, 공용 카드 시설 Lv.2는 카드 단계 ×1.10이며, 0.1초 틱 올림과 자동 카드 재시작 0.1초도 반영했다. 제작 가동률은 처리 시간에 반영한다. 실제 카드 병렬이나 라인 사이 재료 공유는 이 순차 모델보다 처리량을 높이거나 낮출 수 있다.
4. 수동 모델은 원광 채굴 노력 `Σ(소요 수량/가동 처리율)`과 제작 시간을 더한 후, 각 원광 총 공급 한도에 맞춰 완성량을 제한했다. 자동과 수동 모두 마감까지 완성된 수량만 계산한다. 가공 추가 G는 `완성 수량×(판매가−원광 원가)`다. 남은 원광은 직접 판매와 가공 시나리오에서 같은 가격으로 팔 수 있다고 두었다.

## 3. 과수익과 투자 검토

| 품목 | 초안 G / 자체 초 | 권장 G / 자체 초 | 원광 충분 1라인 추가 G/분 | 2시간 평균 추가 G/분 | 8시간 평균 추가 G/분 |
|---|---:|---:|---:|---:|---:|
| 고대 기어 | 905 / 3초 | 875 / 12초 | 3,020 → **605** | 237 → 190 | 712 → 570 |
| 용암 동력핵 | 3,932 / 15초 | 3,750 / 25초 | 2,498 → **1,379** | 272 → 228 | 820 → 685 |
| 심연 봉인구 | 10,350 / 30초 | 9,800 / 30초 | 1,643 → **1,328** | 805 → 677 | 2,508 → 2,109 |

- **고대 기어는 875G·12초.** 재고가 쌓였을 때 순수 가공 이익이 3,020→605G/분이다. 보통 공급에서는 제작 시간을 늘려도 광물 수급이 먼저 막히므로 가격도 내려야 평균 수익이 줄어든다.
- **용암 동력핵은 3,750G·25초.** 내열 합금 단계까지 합치면 전체 41초다. 동일한 용암 결정 공급에서 후반 평균 추가 이익은 820→685G/분이다.
- **심연 봉인구는 9,800G.** 8시간 풍부한 공급에서도 2,109G/분으로 가장 높다. 1,200G/분을 후반 비교선으로 삼을 경우 완제품은 약 0.414개/분 이하가 필요하다. 실제 희귀 광맥의 수급과 2라인 생산량을 측정해 반복 판매의 허용 수익을 판단한다.
- **초기 제작과 중간품.** 기존 0초 3종에 최소 자체 2/2/3초를 권장한다. 30분 강철 완성은 97→85개, 가공 추가 이익은 873→765G로 줄었다. 즉시 투입 가격 역전은 마정 엔진 1,201G, 정밀 기계 1,482G로 해소하고 특수 합금을 572G로 높여 중간품 대비 최소 이익 여유를 맞췄다.
- **자동 판매와 예약 재고.** 제작 목표치는 현재 상한이며 자동 판매는 전량을 판다. 연구·건설·후속 레시피용 예약량을 먼저 보호하고 초과분만 자동 판매할 것을 권장한다. 터널 의뢰용 마법 합금 5개를 예약하는 흐름을 회귀 검증한다. 동일 틱 다중 시설이 예약할 때 중복 소비도 방지한다.
- **가격에 연동된 비용.** 현재 자동 판매 해금 비용은 판매가×20이어서 강철 100→880G, 석탄 벽돌 80→380G가 된다. 보유한 허가는 유지하고 새 허가 비용은 판매가에서 분리해 연구 단계에 맞춘다. 거래 단가(기본 시세×1.3), 납품 배송료(시세의 10%를 적용하는 기준식), 납품 점수·명성도 같은 가격에 연결돼 있어 별도로 다시 검증한다.
