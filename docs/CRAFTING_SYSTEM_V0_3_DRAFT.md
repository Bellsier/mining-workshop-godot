# 《채굴 공방》 제작 시스템 통합 설계 v0.3 (2026-11-23)

> 사용자 대화에서 결정된 **설계 기준**을 한곳에 정리. **게임 코드·main·저장 데이터 미변경.** 판매가·제작 시간·해금 조건은 수치 검증 전까지 최종 확정이 아닌 설계 기준. 기존 18종의 가격 초안은 [CRAFT_PRODUCT_PRICING_V0_1.md](CRAFT_PRODUCT_PRICING_V0_1.md) 참조.

## 범위 및 분리
- 일반 제작품 **기존 18종 + 신규 32종 = 50종**. 기존 18종의 ID와 자동 제작 설정은 호환성 검토 전까지 보존.
- **장비 제작 별도**: 곡괭이·탐험 장비 등은 장착·성장용이며 일반 판매품 50종에 미포함. 기존 '철제 공구'는 판매 가능한 일반 제작품, '철 곡괭이'는 장착 장비로 구분.
- 시설/연구/스토리용 재료는 일반 제작품과 공유 가능하나 사용처와 재고 보호 필요.
- 확정 원광 **29종 v0.8 가격은 변경하지 않음**. v0.9 가격안은 미승인.

## 판매가·시간·해금·자동화 설계 기준
1. **판매가**: 최종 원광 환산 원가 × 약 1.25 (기초), 고급품은 1.30~1.50 후보. 중간품 판매가를 누적 원가로 재차 더하지 않음. 희귀도·제작시간·재료 수급량·실제 골드/분 반영 후 **50종 전부 개별 가격 확정 필요**.
2. **제작 시간**: 기초 2~4초 / 지역 특산 5~10초 / 고급 12~20초 / 최상급 25~40초를 초기 구간으로 사용. 기존 18종의 0초 제작품 등 현행 수치와의 차이는 실행 검증 후 조정.
3. **해금**: 기초는 초기 해금, 지역 특산품은 지역 발견 및 연구, 최상급품은 연구·공방 업그레이드와 연결. 기존 세이브의 이미 해금된 레시피는 유지.
4. **자동화**: 제작 의존 순서 및 중간 재료 재고 보존; 연구·건설용 예약 재고는 자동 판매 대상에서 제외. 50종 메뉴는 기초/지역 특산/고급 부품/특수로 필터링. 모바일 568×320 가로 입력·스크롤 유지.
5. **장비**: 곡괭이는 장착 효과와 채굴력으로 밸런싱, 판매용 가공품의 25% 가산 규칙을 적용하지 않음. 요구 채굴력보다 **4.7 낮아도 채굴 가능** 규칙 유지.
