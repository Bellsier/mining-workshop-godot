# 《채굴 공방》 통합 게임 설계 v1.0 — 디렉터 제안안

> 상태: **검토 전 초안**. 이 문서는 대화에서 수립한 통합 설계 방향을 보존한다. 기존 확정 설계를 대체하지 않으며, 신규 제안과 수치는 사용자 승인 전까지 미확정이다.
> 작성 기준: 2026-11-23. 게임 코드 변경·병합·배포 없음.

## 1. 핵심 정체성과 게임 순환
작은 공방에서 시작해 살아 있는 마을과 잊힌 지하 세계를 되살리는 따뜻한 탑다운 픽셀 게임. 핵심 순환은 **채굴·채집 → 가공·제작 → 판매·연구 → 마을 성장 → 탐험·발견 → 새로운 자원 획득**. 채굴만이 아닌 제작, 주민, 탐험, 이야기의 상호 연결을 우선한다.

## 2. 채굴·광물·도구
### 기존 합의
- 거점 중심 **동심원 기반 희귀도 분포**. 멀수록 고급 광물 출현 가능성이 높고, 가까운 곳에도 낮은 확률로 고급 광물이 나온다. 지역 고유 광물 및 스토리 잠금 광물은 별도 조건을 따른다. 지하 B1~B4는 층별 조건을 둔다.
- 광맥 유형 생성 확률: **소형 50%, 중형 30%, 대형 15%, 초대형 3.5%, 특수 1.5%**. 특수는 거대 크기와 별개의 유형이며 채굴 전 외형으로 구별한다.
- 광맥 매장량 소진 시 '채굴 완료' 메시지와 소액 골드 보상 지급 후 광맥 제거. 자동 채굴에도 적용하며 중복 지급·저장 손실을 방지한다.
- 요구 채굴력보다 **4.7 낮아도 채굴 가능**. 수식: 최소 채굴력=max(0, 요구 채굴력-4.7).
- 광물 가격 v0.9는 잠정 경제 기준. 매장량은 광물 가격과 광맥 크기를 반영한다.
- 직접 채굴은 숙련도 경험치 획득, 자동 채굴은 경험치 미지급.

### 신규 제안 / 미검증
- 도구 5단계, 내구도 없음. 채굴력 차이에 따른 속도: -4.7 → 25%, -3 → 50%, -1.5 → 75%, 0 → 100%, +5 → 125%. 연속 보간식은 미정.
- 광물 등급별 요구 채굴력: 일반 5, 고급 10, 희귀 15, 영웅 20, 전설 25.
- 중형 기본 매장량: 일반 45, 고급 28, 희귀 18, 영웅 10, 전설 5. 가격 보정계수=clamp(sqrt(등급 기준가격/광물 가격),0.8,1.2), 기준가격 일반10·고급50·희귀140·영웅360·전설1200. 최종 매장량=max(1,round(기본 매장량×가격 보정계수×크기 배율)).
- 크기 배율: 소형 0.5, 중형 1, 대형 2, 초대형 4. 특수 광맥은 크기 별도 추첨.
- 고갈 보상 제안: 소형 5G, 중형 15G, 대형 35G, 초대형 80G. 특수 보상은 미정.
- 특수 광맥 하위 유형(고순도·혼합·고대·변이)은 후보이며 확정 아님.

## 3. 제련·제작·경제 (신규 제안)
제작 계열 네 가지: 기본 가공(주괴·판재·부품), 장비(곡괭이·방어구·탐험 도구), 공방 설비(용광로·기계·자동화), 생활·장식(가구·조명·주민 의뢰품).
- 가공품 가치는 투입 재료 판매가 대비 평균 20~35% 높은 수준을 목표로 하되 연료·가공 시간·재료 소비를 포함해 재검증.
- 주민 주문은 일반 판매보다 10~25% 높은 보상. 기본 판매가는 고정하고 주문·특별 행사에 보너스.
- 자동 제작·자동 판매는 플레이어가 해금하고 직접 설정.
- 세부 제작법·재료 소비·설비 단계·골드 소모처는 미정.

## 4. 마을·건축·생활 (신규 제안)
마을 성장 5단계:
1. 작은 거점: 집·공방·소수 주민, 기본 채굴·제작
2. 공방 마을: 상점·창고·작업 시설, 주문·주민 유입
3. 성장하는 마을: 주택·정원·공공시설, 농사·친밀도
4. 기술 마을: 연구소·복구 시설·박물관, 고대 기술
5. 화합의 마을: 지역 문화 공존, 공동 시설·후반 이야기

건물은 기능과 외형을 함께 증축한다. 주요 건물은 지정 부지에 증축, 가구·장식·정원·길은 자유 배치하는 혼합형. 농사는 작은 정원→온실·특수 작물로 확장하며 강제 일과가 아닌 선택형 생활 콘텐츠.

## 5. NPC·친밀도 (신규 제안)
친밀도 0~100: 0~19 기본 대화, 20~39 일상·취향, 40~59 개인 의뢰·선물, 60~79 개인 서사, 80~100 고유 이야기·협력 기능. 대화·선물·의뢰·사건 해결로 상승, 매일 대화하지 않아도 감소하지 않음. 주민은 아침 출근, 낮 작업, 저녁 귀가·광장 활동 등 일정과 날씨·스토리 반응을 갖는다. 주요 인물별 고유 서사.

## 6. 지역 탐험·전투·교통 (기존 지역 기반 신규 제안)
| 지역 | 탐험 요소 | 보상·연결 |
|---|---|---|
| 푸른 초원 | 초보 탐험, 숨겨진 동굴 | 기본 자원·설계도 |
| 이끼숲 | 장인 표식, 자연 퍼즐 | 장인 제작법·대장 단서 |
| 붉은 바위 산맥 | 낙석·수직 지형·폐광 | 금속·광산 설비 |
| 안개 늪지 | 시야 제한·독성 안개·기계 수리 | 정화 기술·기록 |
| 서리 고원 | 추위·얼어붙은 통로 | 방한 기술·대장의 과거 |
| 별빛 수정 지대 | 결정 공명·빛 반사 퍼즐 | 에너지 연구·과학자 구조 |
| 잿불 화산 지대 | 열기·용암 통로 | 고온 제련·장비 |
| 고대 유적 | 고대 회로·봉인 장치 | 유물·문명 기록 |

전투는 탐험의 보조 시스템. 기본 공격·회피·방어·장비 효과, 지역별 적 행동, 희귀 제작 재료·연구 단서 보상. 주요 스토리 전투는 준비와 장비로 난도를 완화. 이동은 도보→광산 레일·수레→복구한 고대 이동 장치. 첫 방문은 직접 탐험.

## 7. 연구·박물관 (신규 제안)
연구 작업대(기본 기술), 연구소(광물·기계·에너지), 박물관(유물·역사 전시), 복원 공방(고대 장치 수리), 공동 연구 시설(과학자 구조 이후 고급 연구). 유물 전시 시 설명·주민 방문·대화·연구 해금. 연구 흐름: **광물 분석→설계도 발견→시제품 제작→시설 적용**.

## 8. 스토리·세계관 (기존 결정 존중)
핵심 연결: 고대 사원·정신체·침식 유물, 지하 문명 이주와 붕괴, 아버지의 선행 탐사, 서리 고원의 비극, 대장의 귀환과 아버지 기록 발견, 대장의 이끼숲 조사·실종, 과학자 사고 및 대장 실종 의혹에 따른 집단 갈등, 플레이어의 탐험·과학자 구출·진실 발견·화해.
- 이끼숲 봉인 상자와 침식 유물은 서로 다른 축. 봉인 상자는 고대 장인이 제작했으며 제작·발견 순서는 기존 청사진을 우선.
- 대장의 최종 행방·아버지의 탐사 깊이·과학자가 알고 있는 진실은 미확정.
- 두 집단 사이 고의적 거짓말은 없음. 주민 교류·공동 시설 복구·경관 변화로 화해 표현.
- 엔딩 이후에도 마을 생활·제작·탐험 지속 제안.
- **주의:** 이 문서의 간략한 시간 순서가 기존 청사진의 정확한 고대 문명·사원·침식 유물 연혁을 대체하지 않는다. 원본 대조 필수.

## 9. 고대 사원·심리 호러 (기존 핵심 유지, 일부 제안)
1인칭 고대 사원 미로. 환각 수치(Sanity), 제한된 항정신제, 숨은 내성, 봉인 회로. 비물질 정신체의 환청·모방·시야 왜곡·조작 교란. 백미러 엔딩과 돌기둥 엔딩 유지. 과학자 구조 후 정신체 연구와 치료 연결. 웃는 가면의 안내자 및 일부 구체적 연출은 신규 제안이며 기존 설정과 충돌 여부 검토 필요. 번쩍임·카메라 흔들림 감소 접근성 옵션 제안.

## 10. UI·저장·플랫폼
PC 키보드·마우스, 모바일 가로 우선·터치. 수첩에 지도·제작법·연구·주민·스토리 기록 통합. 중요 상태 변경 시 안전한 자동 저장, 수동 저장 별도 검토. 기존 저장 호환·버전별 이관·손상 저장 보호·진행 불능 방지. 글자 크기·시각 효과·조작 설정.

## 11. 개발 우선순위 (제안)
1. 공방의 재미: 채굴·제련·제작·판매·일꾼·자동화 안정화
2. 살아 있는 마을: 건물·주민·친밀도·의뢰·가구
3. 탐험과 발견: 지역·이동·전투·퍼즐·연구·박물관
4. 세계관과 완성: 대장·아버지·과학자·지하 문명·사원·엔딩·후일담
