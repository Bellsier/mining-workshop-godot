# 《채굴 공방》 경제·채굴 밸런스 검토 v0.1

> **상태: 정적 수치 검토 / 제안 / 미승인.** 2026-11-23. `GAME_DESIGN_V1_1_DRAFT.md` 후속. 게임 코드, 저장 데이터, 기존 가격표 미변경. **실제 플레이 테스트·Godot 테스트 실행 결과가 아니다.**

## 1. 검토 근거와 한계
- 기존 Godot `scripts/world/world_data.gd`는 `data/web_catalog.json`의 웹 게임 경제·월드 데이터를 읽는다. `tools/economy_parity_test.gd`는 웹 원본 커밋 `7484ccd` 대비 70틱 생산·자동 제작·판매·직원 업그레이드·광맥 채굴 등 **수치 동등성**을 검사하도록 작성되어 있다. **이번에 테스트를 실행한 것은 아니다.**
- `tests/fixtures/economy_web_fixtures.json`의 예시: 광석 자원은 `iron/coal/mana/crystal/rareMetal/relic/cosmicShard/plasma` 등 구형 내부 키이며, 최종 29종 광물 명칭·가격과 **직접 대응하지 않는다**. 따라서 기존 수익률을 새 광물 가격에 그대로 대입하는 것은 금지한다.
- 제안된 신규 광맥 매장량·소진 보상·광물 가격 v0.9는 **현재 Godot 구현의 실측값이 아니다**. 아래는 설계 후보의 산술 점검이다.

## 2. 확정 규칙과 검토 보류
**유지:** 거리 링 희귀도 + 지역 고유 광물, 광맥 유형 50/30/15/3.5/1.5%, 특수 외형 구별, 요구 채굴력보다 4.7 낮아도 채굴 가능, 가격과 매장량의 연계, 광맥 소진 시 보너스 1회 후 제거, 저장 복원 및 중복 지급 방지.

**보류:** 광물 가격 v0.9, 기본 매장량 일반45/고급28/희귀18/영웅10/전설5, 크기 배율 0.5/1/2/4, 속도 25~125%, 소진 보너스 5/15/35/80G, 제작 마진 20~35%, 주문 보너스 10~25%. 이 수치를 코드에 반영하지 않는다.

## 3. 단순 매장량 후보의 위험
중형 광맥의 매장량 후보(45·28·18·10·5)와 v0.9 광물 가격의 대표값을 곱한 **광맥 전체 원광 판매 총액**:

| 예시 광물 | 잠정 가격 | 중형 후보 수량 | 전체 판매 총액 |
|---|---:|---:|---:|
| 석탄 | 5G | 45 | 225G |
| 철 | 14G | 45 | 630G |
| 녹옥석 | 40G | 28 | 1,120G |
| 금 | 110G | 18 | 1,980G |
| 티타늄 | 300G | 10 | 3,000G |
| 생명의 결정 | 900G | 5 | 4,500G |
| 심연 결정 | 1,550G | 5 | 7,750G |

*계산: 가격 × 기본 수량. 가격 보정계수, 광맥 크기 추가 보정, 소진 보너스, 이동·채굴 시간은 **미적용**.*

**판단:** 고급 광맥의 총액이 높은 것은 자연스럽지만, 같은 전설 등급의 생명의 결정과 심연 결정은 후보 중형 광맥 총액이 **약 1.72배** 차이 난다. 이는 의도한 지역 보상 격차일 수 있으나, 도달 시간·채굴 시간·제작 수요를 확인하지 않고 매장량을 확정하면 후반 수익이 급격히 상승할 위험이 있다. 반대로 고가 광물의 수량을 과도하게 줄이면 제작 재료 부족이 발생할 수 있다.

## 4. 광맥 유형 비율과 기대 수량
특수 1.5%를 별도 유형으로 두고 일반 4개 유형만 조건부로 보면, 제안 크기 배율 0.5/1/2/4의 **전체 광맥당 가중 기여도**는 `0.50×0.5 + 0.30×1 + 0.15×2 + 0.035×4 = 0.99`. 일반 유형이 98.5%이므로 **일반 유형 내 조건부 평균 배율 = 0.99 / 0.985 ≈ 1.0051**. 특수 광맥의 크기·수량·보상은 아직 정의되지 않아 전체 평균 수량은 계산할 수 없다.

**판단:** 현재 크기 배율은 일반 광맥 기준 평균 수량을 거의 중형 1배에 맞춘다. 따라서 유형별 배율 자체보다 **광물별 기본 수량과 채굴 시간**이 경제를 크게 좌우할 가능성이 높다. 단, 소형이 절반이므로 플레이 체감은 평균과 다르다.

## 5. -4.7 채굴력과 시간당 수익
**확정:** `채굴 가능 ⇔ 플레이어 채굴력 ≥ max(0, 광맥 요구 채굴력 − 4.7)`.

**미확정:** 부족분에 따른 실제 채굴 속도. 이전 후보 `-4.7→25%, -3→50%, -1.5→75%, 0→100%, +5→125%`는 단계 사이 보간식과 자동화 적용 여부가 없어서 아직 구현 명세로 사용 불가.

검증 시 **수익/시간**은 `(원광 판매가×실제 채굴 수량 + 고갈 보너스 − 운영 비용) ÷ (접근 시간 + 채굴 시간 + 대기·제작 시간)`으로 비교한다. 채굴력이 낮은 광맥을 캘 수 있어도 느려서 비효율적일 수 있도록 하되, 진행 막힘을 일으키지 않아야 한다.

## 6. 제작·판매·자동화의 우선 위험
1. **원광 판매 vs 가공:** 가공품 판매가 − 원재료 판매 기회비용 − 연료/운영비가 양수여야 보람이 있으나, 자동 제작의 반복 수익이 수동 채굴을 압도하면 안 된다.
2. **골드 소모처:** 직원 고용·업그레이드, 시설·공방 확장, 연구, 터널 공사, 마을 복구 비용과 수익 성장률을 같은 시간축에서 비교해야 한다.
3. **자동화:** 직원 생산량, 제작 큐, 자동 판매, 저장 복원 후 오프라인/중복 틱 처리에 따른 재화 증식·소실을 검사한다.
4. **재료 병목:** 고가 광물은 수익뿐 아니라 장비·연구·스토리 제작 수요를 감안해야 한다. 희귀 광맥의 기대 등장 횟수와 매장량으로 **필수 제작 가능성**을 검증한다.
5. **특수 광맥:** 1.5% 유형이 크기 보정까지 중첩될 때 극단적 수익이 발생할 수 있으므로 유형·수량·보상을 별도 표로 설계한다.
