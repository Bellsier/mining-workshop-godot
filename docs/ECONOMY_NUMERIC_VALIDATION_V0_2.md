## 2. 가장 중요한 발견: 기존 제작 판매가와 신규 원광 가격은 양립 불가
**아래는 가정 실험이며, 현행 게임의 실제 적자라는 뜻이 아니다.** 구형 내부 `iron`을 신규 '철 15G', `coal`을 '석탄 5G', `mana`를 '마정석 74G'로 **임시로 대응**해, 구형 레시피의 판매가를 그대로 유지할 경우를 계산했다.

| 구형 레시피 | 기존 판매가 | 신규 원광 가격 기준 최소 재료 기회비용 | 차액 |
|---|---:|---:|---:|
| 강철 steel = iron×2 + coal×1 | 5G | 35G | **-30G** |
| 석탄 벽돌 coalBrick = coal×3 | 4G | 15G | **-11G** |
| 철제 공구 ironTool = iron×4 + coalBrick×1 | 14G | 75G (coalBrick 원광 환산) | **-61G** |
| 마정 램프 manaLamp = coalBrick×2 + mana×2 | 30G | 178G (석탄 6개 30G + 마정석 2개 148G) | **-148G** |

※ 기회비용은 원광을 직접 판매했을 때 얻을 수 있는 금액. 제작 시간·연료·판매 보너스·생산량 배율 제외. `coalBrick`을 기존 판매가 4G로 외부 조달한다고 가정한 원가는 다르므로 **동일한 '원광에서 시작' 경로**로 비교했다. `ironTool` 원재료는 철 4개 + 석탄 3개 = 60+15=75G. 이 계산은 **서로 다른 경제 버전의 수치를 섞으면 제작 동기가 무너진다**는 위험을 확인하는 것이며, 현재 게임의 실측 손익이 아니다.

**디렉터 결론:** 신규 광물 가격만 교체해서는 안 된다. 신규 경제 적용 시 레시피 원재료 ID·제작량·판매가·필요 시간·판매 보너스를 **하나의 버전 묶음**으로 재설계해야 한다. 기존 18개 레시피와 저장의 자동 제작 대상은 마이그레이션 전까지 유지한다.

## 3. 기존 공방 투자 비용과 시간당 회수의 연결
현행 `data/web_catalog.json` 기준 공방 건설 G비용(순서 1~8): **500, 800, 1,280, 2,048, 3,277, 5,243, 8,389, 13,422G** (`ceil(500×1.6^count)`; 7~8번째는 추가 제작 재료 필요). **정정:** 앞선 계산에서 부동소수점 `500×1.6²`를 1281로 표시할 가능성이 있으므로, 실제 코드의 `ceil`과 이론상 정수 금액을 구분해야 한다. `ceil(500×1.6²)`의 수학적 값은 1,280G이나 컴퓨터 부동소수점에서는 1,280.0000000000002일 수 있어 1,281G가 나올 수 있다. **정확한 실제 Godot 결과는 실행 검증 필요**.

**판단:** 신규 가공 마진 목표를 정할 때 `투자 회수시간 = 공방 비용 ÷ 추가 순이익(G/분)`으로 비교한다. 건설비뿐 아니라 생산속도·원재료 수급·자동 판매·연구 해금 조건도 포함한다.

## 4. 광맥 수량 시나리오 — 아직 가정
신규 매장량 제안(일반45·고급28·희귀18·영웅10·전설5)은 아직 **등급별 광물 매핑과 특수 광맥 수량이 확정되지 않음**. 4개 일반 유형 확률 50/30/15/3.5%와 배율 0.5/1/2/4의 기여도 합은 0.99; 일반 유형 내 조건부 평균 배율 `0.99/0.985≈1.0051`. **특수 1.5%를 포함한 전체 평균은 미정**. 정수 매장량의 반올림, 가격별 보정, 소진 보상까지 정해야 실질 기대값 계산 가능.
